About the Project

AURA: Autonomous Unified Robotic Adaptive

AI-Based Autonomous Wall Painting Robot Integrating Deep Learning Segmentation, Color Recommendation, and Adaptive Spray Control

AURA unifies deep-learning spatial segmentation (YOLOv8), OpenCV-based homography calibration, raster toolpath generation, pyserial-mediated Arduino adaptive spray control, and AI-based color recommendation into a single undergraduate-scale prototype: a 2D vertical gantry driven by dual-X and single-Y NEMA 23 stepper motors. A captured wall image is segmented into paintable regions, calibrated into real-world coordinates, converted into a raster toolpath, and executed by an Arduino-controlled spray system. Performance is evaluated against recognized external standards — ISO 9283, the COCO protocol, ASTM D823, ISO/IEC 25010, and IEEE 1872 — rather than internally defined thresholds.

A USB/HD camera captures the wall; YOLOv8 outputs a paintable-region mask; OpenCV homography calibration (physical corner markers) maps pixel coordinates to millimeters; a raster (boustrophedon) planner generates the toolpath; commands stream over pyserial at 115200 baud to an Arduino Mega 2560 wired directly to TB6600 drivers, which drive the NEMA 23 motors and spray subsystem.

Tech Stack

  • Python 3.11
  • PyTorch + CUDA 12.1
  • Ultralytics YOLOv8 (Instance Segmentation)
  • OpenCV
  • pyserial
  • Roboflow (dataset annotation)
  • Kaggle Tesla T4 (training)
  • Arduino Mega 2560 + TB6600 drivers (direct-wired, no RAMPS)

Evaluation Standards

Standard Metric What It Measures
ISO 9283:1998 Motion (Positional) Accuracy Commanded vs. measured pose (mm) — manipulating industrial robot performance criteria and test methods.
COCO Protocol Segmentation Accuracy IoU and mAP at IoU ≥ 0.50, matching Ultralytics' own YOLOv8 evaluation framework.
ASTM D823 Spray Consistency & Coverage Uniformity Uniformity of applied coating across test panels/wall regions; percentage of area evenly coated with no gaps or excess overlap.
ISO/IEC 25010:2011 Color Recommendation Quality 5-point Likert rating of palette coherence, suitability, and satisfaction (SQuaRE usability sub-characteristics).
IEEE 1872-2015 Overall System Integration Structured end-to-end integration assessment against standard ontologies for robotics and automation.
