AURA

AI-Based Autonomous Wall Painting Robot

AURA unifies YOLOv8 deep-learning segmentation, OpenCV homography calibration, raster toolpath generation, and Arduino-driven adaptive spray control into a single gantry system that perceives a wall, recommends a color palette, and paints it — closing the loop from camera to motor.

View Dashboard About the Project

What AURA Does

Perception, recommendation, and execution in one pipeline

🎨

Color Recommendation

An AI-assisted module analyzes a reference image or preference input and proposes a coherent color palette, rated by human evaluators for visual coherence and suitability.

🧿

Live Masking View

YOLOv8 instance segmentation identifies paintable wall regions from live or captured camera frames, visualized as an overlay mask before, during, and after painting.

📊

Performance Metrics

System performance is benchmarked against recognized external standards — ISO 9283, COCO protocol, ASTM D823, ISO/IEC 25010, and IEEE 1872 — not internally invented thresholds.
