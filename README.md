# Thesis

Repository for thesis project work.

## Overview

This repo contains research, notes, code, and documents related to the thesis project.

## Structure

- `AURA Vault/` — Obsidian vault for notes and research
- `create_vault.py` — Python utility for vault setup
- Additional files and folders to be added as the project grows

## Setup

Clone the repo and open the Obsidian vault directly, or run Python scripts as needed.

```bash
git clone https://github.com/<your-username>/thesis.git
cd thesis
```
